## 本轮新增

- research-plan-v2：11个必填字段。包含目标、可证伪假设、数据划分、基线、改进路线、消融、指标、预设验收条件、实施步骤、资源里程碑和风险。保留全文/摘要及引用核对，兼容旧版方案显示与报告导出。
- 数字识别教学项目：显式独立新建，不将已有研究问题替换为数字识别。该项目的上游问题/痛点为明确标记的教学假设，方案、实验设计、模型代码和结果解读真实调用 DeepSeek。
- 模型仅生成受约束的 sklearn 分类器工厂；固定评价器控制独立划分、噪声、训练、指标和预设判据。最多依据错误修复一次。
- 三方法×三种子：线性基线、无增强RBF、噪声增强RBF。模型工厂经过AST白名单和模型参数检查后才会执行。
- 后端重新核算逐次指标与汇总均值/标准差，以及验收判断，拒绝缺失、非有限值和自相矛盾的结果。
- 保存提示词、模型输出、尝试记录、代码、固定协议、评价器、环境、原始指标、CSV、Markdown报告和产物哈希清单。白名单下载接口同时核对文件完整性。
- 页面显示汇总指标、逐种子指标、真实图像、混淆矩阵、负面结果、边界说明与产物下载。
- 方案输入指纹绑定实验结果；上游变更会使旧运行和结果来源失效，旧结果仍保留供追溯。
- 通用脚本与外部结果导入继续可用；当前没有为任意领域自动生成可信评价器。

## 使用

普通课题：依旧按四阶段操作；旧版方案可查看，重新生成后采用结构化格式。

数字示例：点击“新建研究项目”，再点“数字识别教学实验”。生成并确认方案 → 实验验证中生成设计 → “生成代码并运行真实实验” → 查看程序指标 → “分析实际结果”。

可选依赖：自动训练需要 Python 3.11+（本机验证3.14）；基础网页仍支持3.10。在服务实际使用的 Python 环境运行：

```powershell
python -m pip install -r requirements-experiments.txt
```

使用便携版虚拟环境时：`python bootstrap.py --install-experiments`。无需GPU。依赖安装和包版本会记录在实际运行环境中。

## 边界

达到均值阈值不表示统计显著或有学术创新。三个随机划分上的结果不能推广到其他领域。sklearn digits 为真实数据集，但此处仍是教学基准。其他课题的科学有效性取决于数据、协议和研究者审查。

固定协议项目的执行字段由后端锁定，保留 modelDraft 审计原稿。模型原稿不会传给后续模型任务；下游只读取已接受方案和权威协议。
